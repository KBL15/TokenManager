TokenMonitor 设置

监控千问/百炼 Token Plan 的额度用量。凭据存在 Windows 凭据管理器里， 不会写进配置文件。 凭据管理器不可用

数据源

自动
先试 AccessKey 接口，失败回退 Cookie。不确定选哪个就选它。
Cookie 网关
Token Plan 个人版走这条。需要从浏览器复制 Cookie。
AccessKey 接口
官方 OpenAPI，团队版适用。需要 RAM 用户的 AccessKey。
自定义接口
接任意 HTTP 接口，自己指定字段位置。接口改版时用。

Cookie 网关（个人版）未配置

不用手动抄 Cookie。cURL 里包含的 Cookie、请求头会被自动解析出来。
抓取方法：打开百炼控制台「订阅套餐」页 → F12 → Network → 筛选 tokenplan/personal/api/v2/usage → 复制这条请求的整行 Cookie。注意不能用页面导航请求的 Cookie。
数据网关的域名和页面域名不是同一个——这是「抄错 Cookie 导致登录失效」的头号原因。

AccessKey 接口（团队版）未配置

需要 RAM 用户具备 AliyunTokenPlanReadOnlyAccess 策略。 这组接口返回的是席位制额度，个人版账号调用会失败。

自定义接口

路径写法：a.b[0].c。接口返回的是 0–1 小数时，把下面的倍率填 100。

刷新与提醒

数据源说明：Token Plan 个人版的用量没有公开 API，只能通过控制台网关读取， 因此需要浏览器 Cookie；Cookie 会过期，届时重新粘贴一次即可 （卡片上会明确提示）。团队版可改用 AccessKey 接口，不会过期。
